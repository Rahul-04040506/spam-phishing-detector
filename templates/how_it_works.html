How The System Works

1. User Input

The process begins when a user enters a message into the system. This message can be an SMS, email, or any text containing potential spam or phishing content. The system is designed to analyze real-world communication data.

2. Text Preprocessing

The input message is cleaned and prepared for analysis. This includes converting text to lowercase, removing unnecessary characters, and standardizing the format so that the model can process meaningful patterns effectively.

3. Feature Extraction (TF-IDF)

The processed text is converted into numerical form using TF-IDF (Term Frequency–Inverse Document Frequency). This technique highlights important words and phrases such as “account”, “verify”, or “offer”, enabling the system to understand the significance of terms in the message.

4. Logistic Regression Model

A Logistic Regression model is used to classify the message as Spam or Not Spam. It learns patterns from labeled data and makes predictions based on the probability of a message being spam. This model is efficient and suitable for real-time applications.

5. Phishing Detection (Rule-Based)

In addition to machine learning, the system uses rule-based logic to detect phishing attempts. It checks for suspicious patterns such as the presence of URLs, keywords like “verify”, “bank”, or “urgent”, and unusual message structures. This helps identify subtle threats that the model might miss.

6. Confidence Calculation

The system calculates a confidence score for each prediction based on probability values. This score indicates how certain the model is about its classification, helping users understand the reliability of the result.

7. Result Presentation

The final result is displayed to the user, showing whether the message is Spam or Not Spam, along with the confidence percentage and phishing status. Suspicious keywords may also be highlighted for better transparency.

8. System Limitations

The system is based on learned patterns and predefined rules, so it may not detect highly advanced or new phishing techniques. Some messages with subtle context may be misclassified. Therefore, results should be considered as supportive insights rather than absolute conclusions.
